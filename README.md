# ELIMORA Studio

Первая версия сайта авторской студии ELIMORA: интерактивный первый экран, направления, услуги и анкета с предварительной рекомендацией и скачиванием брифа.

## Запуск

Сайт не требует сборки. Откройте `index.html` или запустите `python3 -m http.server 8000` из корня репозитория.

## Публикация на GitHub Pages

Settings → Pages → Deploy from a branch → main → / (root) → Save.

После включения адрес: https://elvirasaarova.github.io/elimora-site/

## Файлы

- `index.html` — семантическая разметка.
- `styles.css` — адаптивное оформление.
- `app.js` — навигация и анкета, без внешних API.
- `assets/` — иллюстративная сцена исходной концепции. Она не является реальным клиентским кейсом.

## Текущие границы

- Ответы анкеты хранятся только в памяти страницы; бриф скачивается пользователем.
- Приёма заказов, личного кабинета, загрузки исходников, оплаты и WhatsApp-интеграции пока нет.
- Состав и названия старших пакетов Яндекс Карт требуют уточнения. Цены взяты из брифа владельца.
- Услуги не обещают позиции в поиске или количество клиентов.
