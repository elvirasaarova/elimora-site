# ELIMORA Studio

Многостраничный сайт и интерактивный подбор на главной. Размещается на GitHub Pages без сборки.

## Проверка локально

`python3 -m http.server 8000`

## Проверка логики

`node --test tests/recommendation.test.mjs`

## Маршрут анкеты

Задача → сфера бизнеса → отношение к оплате Яндекса (для Карт) → объём → уточнение визуала / сайта при выборе → материалы → рекомендация.

- Отказ от оплаты Яндекса: Базовый, даже если материалов мало.
- Неуверенность: условный платный маршрут с альтернативой Базовый.
- Платные функции и компактный объём: Расширенный.
- Несколько самостоятельных направлений, большой каталог, много тем или мультиссылка: Максимум.
- Недостаток логотипа, фото и информации: список подготовки, без автоматического увеличения пакета.

Пакеты: 9 900 / 15 900 / 23 900 ₽ по предоставленной презентации.

## Приватность и ограничения

Ответы сохраняются в sessionStorage текущей вкладки. Кнопка «Начать заново» удаляет текущий бриф из состояния. Скачать рекомендации можно без отправки данных на сервер. Внешние шрифты и аналитика не подключены. Состав запроса услуг также сохраняется в sessionStorage.

Полноценные авторизация, онлайн-оплата, загрузка файлов и автоматическая отправка уведомлений не подключены. Анкета и каталог готовят текст для ручной отправки в Telegram. Контакт: https://t.me/Elimorastudio. Все рекомендации основаны на ответах, без обещаний трафика и поисковых позиций.

## Источники содержания

Предоставленные владельцем логотип, макеты и презентация тарифов. Пример сайта: https://murommaster.ru/.
Сравнение тарифов Яндекса: https://yandex.ru/support/business-priority/ru/manage/paid-features/faq (проверено 16.10.2026). Цена тарифа Яндекса определяется для конкретной организации и не включена в услуги ELIMORA.

## Портфолио

projects.json содержит подборки по сферам. Изображения в assets/projects оптимизированы в WebP без изменения пропорций. Для новой работы добавьте файл и описание в images соответствующей подборки. Просмотр и фильтры реализованы в projects.js.

## Перед запуском оплаты

Нужны реквизиты исполнителя, согласованные условия оферты и обработки данных, серверная часть личного кабинета, хранения файлов и уведомлений, платёжный провайдер. Текущая страница условий описывает только согласование заказа.
